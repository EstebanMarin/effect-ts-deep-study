A rustlings-style gauntlet: 50 katas, 10 pillars, easy→hard. Each kata is a stub
with a =// TODO= hole plus a pre-written test that is RED until you solve it.
You come from ZIO — these teach Effect v4 on its own terms (pure code, no ZIO notes).

Work top-to-bottom. For each kata:
1. =C-c C-t= cycles the heading TODO -> DOING -> DONE (or tick the =[ ]= checkbox).
2. Open the test (=tests/NN-name.test.ts=) to read the target behaviour.
3. Open the stub (=exercises/NN-name.ts=), fill the =// TODO= until the test is GREEN.
4. Re-run the pillar test; move on.

Target = *=corepack pnpm gauntlet=* reaches *50/50 green*. It starts at *0/50*.

** Editor note (don't panic)
Your editor may show red squiggles on =it.effect= (a Scope type quirk) and
"unused variable" hints on the =// TODO= holes. These are IDE-only. The source of
truth is =corepack pnpm typecheck= (exits 0). Ignore the squiggles.

* Effect v4 (beta.98) API gotchas vs the blog posts               :reference:
The beta differs from many v4 announcement posts. Ground truth (from the installed
package; full export dump in =docs/reference/v4-api-surface.md=):
- *Services*: =Context.Service= — there is NO =ServiceMap=. Provide via =Layer.*=.
- *STM*: =TxRef= + =Effect.tx= / =Effect.txRetry= — NO =TRef=/=STM= module.
- *Errors*: no =Effect.catchAll=. Use =Effect.catch= / =catchTag= / =catchCause=;
  =Effect.match= folds BOTH channels (like =ZIO#fold=, not catchAll).
- *Result replaces Either* — no =effect/Either=. =Effect.result= yields a =Result=.
- *Schema*: refinements via =Schema.check(Schema.isInt(), Schema.isGreaterThan(0))=;
  decode families =decodeUnknownSync/Exit/Result=, =decodeTo=; =Struct=/=Union=/=optionalKey=.
- *TestClock* is at =effect/testing=. =it.effect= for virtual time, =it.live= for real time.
- Imports use the =.js= extension (NodeNext), even for =.ts= files.
